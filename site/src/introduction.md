# Introduction

This manual describes the mathematics of ExchangeAlgebra and how to use its Haskell operations. Start with [From journal entries to exchange algebra](overview.md), which maps a journal table onto the algebra's notation. [Definitions and axioms](algebra/definitions.md) then defines how the library represents postings and separates debits from credits. For module documentation and the full API, see the [Haddock reference on Hackage](https://hackage.haskell.org/package/exchangealgebra).
